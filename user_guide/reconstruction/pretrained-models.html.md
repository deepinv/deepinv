# Pretrained Models

## Pretrained reconstructors

Some methods do not require any training and can be quickly deployed to your problem.

#### SEE ALSO
See the example [Use a pretrained model](https://deepinv.org/auto_examples/basics/demo_pretrained_model.html.md#sphx-glr-auto-examples-basics-demo-pretrained-model-py) for how to get started with these models on various problems.

These models can be set-up in one line and perform inference in another line:

```pycon
>>> import deepinv as dinv
>>> x = dinv.utils.load_example("butterfly.png")
>>> physics = dinv.physics.Downsampling(filter="bicubic", noise_model=dinv.physics.GaussianNoise(0.01))
>>> y = physics(x)
>>> model = dinv.models.RAM(pretrained=True)
>>> x_hat = model(y, physics) # Model inference
>>> dinv.metric.PSNR()(x_hat, x) > 29.75
tensor([True])
```

## Description of weights

For each model ([`Denoiser`](https://deepinv.org/api/stubs/deepinv.models.Denoiser.html.md#deepinv.models.Denoiser) or [`Reconstructor`](https://deepinv.org/api/stubs/deepinv.models.Reconstructor.html.md#deepinv.models.Reconstructor)) that has pretrained weights, we briefly summarize the origin of the weights,
associated reference and relevant details. All pretrained weights are hosted on
[HuggingFace](https://huggingface.co/deepinv).

Click on the model name to learn more about the type of model and use `pretrained=True` to use the pretrained weights.
