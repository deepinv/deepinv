# MotionBlurGenerator

### *class* deepinv.physics.generator.MotionBlurGenerator(psf_size, rng=None, device='cpu', dtype=torch.float32, l=0.3, sigma=0.25, n_steps=1000)

Bases: [`PSFGenerator`](https://deepinv.org/api/stubs/deepinv.physics.generator.PSFGenerator.html.md#deepinv.physics.generator.PSFGenerator)

Random motion blur generator.

See Schuler *et al.*<sup>[1](#footcite-schuler2015learning)</sup> for more details.

A blur trajectory is generated by sampling both its x- and y-coordinates independently
from a Gaussian Process with a Matérn 3/2 covariance function.

$$
f_x(t), f_y(t) \sim \mathcal{GP}(0, k(t, t'))
$$

where $k$ is defined as

$$
k(t, s) = \sigma^2 \left( 1 + \frac{\sqrt{5} |t -s|}{l} + \frac{5 (t-s)^2}{3 l^2} \right) \exp \left(-\frac{\sqrt{5} |t-s|}{l}\right)
$$

* **Parameters:**
  * **psf_size** ([*int*](https://docs.python.org/3.9/library/functions.html#int) *,* [*tuple*](https://docs.python.org/3.9/library/stdtypes.html#tuple) *[*[*int*](https://docs.python.org/3.9/library/functions.html#int) *]*) – the shape of the generated PSF in 2D, should be `(kernel_size, kernel_size)`. If an `int` is given, the same value will be used for both dimensions.
  * **l** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the length scale of the trajectory, defaults to 0.3
  * **sigma** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the standard deviation of the Gaussian Process, defaults to 0.25
  * **n_steps** ([*int*](https://docs.python.org/3.9/library/functions.html#int)) – the number of points in the trajectory, defaults to 1000

#### NOTE
Always generates single-channel PSFs of shape `(B, 1, H, W)`.

<hr />

* **Examples:**

```pycon
>>> from deepinv.physics.generator import MotionBlurGenerator
>>> generator = MotionBlurGenerator((5, 5))
>>> blur = generator.step()  # dict_keys(['filter'])
>>> print(blur['filter'].shape)
torch.Size([1, 1, 5, 5])
```

#### f_matern(batch_size=1, sigma=None, l=None)

Generates the trajectory.

* **Parameters:**
  * **batch_size** ([*int*](https://docs.python.org/3.9/library/functions.html#int)) – batch_size.
  * **sigma** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the standard deviation of the Gaussian Process.
  * **l** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the length scale of the trajectory.
* **Returns:**
  the trajectory of shape `(batch_size, n_steps)`

#### matern_kernel(diff, sigma=None, l=None)

Compute the Matérn 3/2 covariance.

* **Parameters:**
  * **diff** ([*torch.Tensor*](https://docs.pytorch.org/docs/stable/tensors.html#torch.Tensor)) – the difference `t - s`
  * **sigma** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the standard deviation of the Gaussian Process
  * **l** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the length scale of the trajectory

#### step(batch_size=1, sigma=None, l=None, seed=None, \*\*kwargs)

Generate a random motion blur PSF with parameters $\sigma$ and $l$

* **Parameters:**
  * **batch_size** ([*int*](https://docs.python.org/3.9/library/functions.html#int)) – batch_size.
  * **sigma** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the standard deviation of the Gaussian Process
  * **l** ([*float*](https://docs.python.org/3.9/library/functions.html#float)) – the length scale of the trajectory
  * **seed** ([*int*](https://docs.python.org/3.9/library/functions.html#int)) – the seed for the random number generator.
* **Returns:**
  dictionary with keys
  - `filter`: the generated PSF of shape `(batch_size, 1, psf_size[0], psf_size[1])`
