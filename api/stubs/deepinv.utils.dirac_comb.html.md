# dirac_comb

### deepinv.utils.dirac_comb(shape, step, device='cpu')

Returns a [`torch.Tensor`](https://docs.pytorch.org/docs/stable/tensors.html#torch.Tensor) with a Dirac comb in 2D (impulse train) at the given step.

* **Parameters:**
  * **shape** ([*tuple*](https://docs.python.org/3.9/library/stdtypes.html#tuple)) – shape of the output tensor.
  * **step** ([*int*](https://docs.python.org/3.9/library/functions.html#int)) – step of the Dirac comb.
  * **device** ([*str*](https://docs.python.org/3.9/library/stdtypes.html#str)) – device of the output tensor.
