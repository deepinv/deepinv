# zeros_like

### deepinv.utils.zeros_like(x)

Returns a [`deepinv.utils.TensorList`](https://deepinv.org/api/stubs/deepinv.utils.TensorList.html.md#deepinv.utils.TensorList) or [`torch.Tensor`](https://docs.pytorch.org/docs/stable/tensors.html#torch.Tensor)
with the same type as x, filled with zeros.
